# DailyHisaab

**Har Kharcha, Hisaab Mein.**

DailyHisaab is a premium, offline-first personal finance and expense tracking application for Android. Designed specifically for the Indian demographic, it provides a secure, locally stored (SQLite) database to manage your daily expenses, monthly budgets, and spending analytics.

## Features
- **Fully Offline:** No internet required. 100% privacy-first.
- **Smart Insights:** Month-over-month trend analysis and budget tracking.
- **Data Export:** Export your financial records to CSV anytime.
- **Material Design:** Premium emerald green and teal aesthetic with adaptive dark/light mode.
